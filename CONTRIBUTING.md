# Как внести вклад

Спасибо, что хочешь дополнить репозиторий! Чтобы всё оставалось единообразным, придерживайся пары простых правил.

## Добавление ресурса

1. Убедись, что материал действительно полезен и по теме (C++, Linux, Computer Science).
2. Добавь пункт в подходящий раздел (или предложи новый, если ни один не подходит).
3. Оформи по шаблону:

```markdown
#### [Название канала](ссылка на канал) — [Название материала](ссылка на материал)
Описание: что это, чем полезно, для какого уровня подходит.

<details>
<summary>Затрагивающиеся темы</summary>

- **Тема 1**
- **Тема 2**

</details>
```

## Что НЕ стоит добавлять

- Материалы низкого качества или с устаревшей/ошибочной информацией.
- Материалы, которые вы не проходили.
- Ссылки без описания.
- Платные курсы.
- Бесплатные курсы, которые рассматривают вас как потенциальные деньги.
