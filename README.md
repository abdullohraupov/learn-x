# C++
## Начальный уровень 🟡

#### Видеоуроки по C++ от [#SimpleCode (Сергей Журавльёв)](https://www.youtube.com/@SimpleCodeIT) — [Основы C++. Программирование для начинающих.](https://youtube.com/playlist?list=PLQOaTSbfxUtCrKs0nicOg2npJQYSPGO9r&si=zM10ZeJnpXWMGh-A)
Плейлист примерно на 200 видео — фактически полноценный курс с нуля до уверенного среднего уровня. Материал подаётся последовательно, без пропусков между темами: каждое новое понятие опирается на предыдущее, поэтому проседаний в понимании почти не возникает. Отдельный плюс — практические задания после тем, которые заставляют реально написать код, а не просто посмотреть видео.

<details>
<summary>Затрагивающиеся темы</summary>

- **Основы** (переменные, циклы, типы данных, операции и т.д.)
- **ООП**
- **STL**
- **Многопоточность**

</details>

## Средний уровень 🟠

#### Видеоуроки по C++ от [Полевой Дмитрий](https://www.youtube.com/@PolevoysProgramming) — [Полный плейлист по книге Скотта Мейерса "Современный и эффективный C++"](https://youtube.com/playlist?list=PL9aFcBWVu5htdYy3scDw9oNdw9Lrff59S&si=q1jZHl-osrEMu-tx)
Разбор книги Скотта Мейерса "Effective Modern C++" — уже не для новичков, а для тех, кто знает базовый синтаксис и хочет понять, *почему* современный C++ устроен именно так. Полевой не просто пересказывает книгу, а разжёвывает мотивацию за каждой фичей (зачем нужны r-value ссылки, почему move лучше copy, в каких случаях `auto` может сыграть злую шутку) и дополняет собственными примерами.

<details>
<summary>Затрагивающиеся темы</summary>

- **r-value ссылки**
- **Семантика перемещения**
- **Умные указатели**
- **Многопоточность**
- **auto**
- **Фигурная инициализация**
- **Шаблоны**
- **decltype**
- **using/typedef**

</details>

# Компьютерное железо и архитектура 🖥️

## Начальный уровень 🟡

#### Видеоурок по полупроводниковому транзистору от [Физика с Юрием Ткачёвым](https://www.youtube.com/@physiovisio) — [Магия транзисторов: как мы научили компьютеры думать с помощью кусочков кремния?](https://youtu.be/_5W_GZOPa8E?si=QQGU2XCNmuWZChcY)
Объясняет, как из отдельных транзисторов строятся базовые логические элементы (И, ИЛИ, НЕ и т.д.), и как из них, шаг за шагом, вырастает вычислительная схема.

<details>
<summary>Затрагивающиеся темы</summary>

- **Логические элементы** (И, ИЛИ, НЕ и т.д.)
- **Резисторно-транзисторная логика**
- **Построение схем из транзисторов**

</details>
