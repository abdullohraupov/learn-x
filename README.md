# Материалы по изучению C++, Linux и Computer Science.
---
#### Примечания ⚠️
Советую установить [Linux-дистрибутив](https://en.wikipedia.org/wiki/Linux_distribution) — так будет удобнее следовать этим материалам. Здесь собраны все ресурсы, которые я когда-либо смотрел, читал и использовал сам. Могу с уверенностью сказать: они стоят вашего времени.

Для этих обучающих материалов необходимо установить:
- **Компилятор C++** (`clang++`, `g++`)
- **Среда разработки** ([Zed](https://zed.dev), [CLion](https://www.jetbrains.com/ru-ru/clion/))

---
## Начальный уровень 🟡

#### Видеоуроки по C++ от [#SimpleCode (Сергея Журавльёва)](https://www.youtube.com/@SimpleCodeIT) — [Основы C++. Программирование для начинающих.](https://youtube.com/playlist?list=PLQOaTSbfxUtCrKs0nicOg2npJQYSPGO9r&si=zM10ZeJnpXWMGh-A)
Плейлист примерно на 200 видео — фактически полноценный курс с нуля до уверенного среднего уровня. Материал подаётся последовательно, без пропусков между темами: каждое новое понятие опирается на предыдущее, поэтому проседаний в понимании почти не возникает. Отдельный плюс — практические задания после тем, которые заставляют реально написать код, а не просто посмотреть видео.

<details>
<summary>Затрагивающиеся темы</summary>

- **Основы** (переменные, циклы, типы данных, операции и т.д.)
- **ООП**
- **STL**
- **Многопоточность**

</details>

## Средний уровень 🟠

#### Видеоуроки по C++ от [Полевого Дмитрия](https://www.youtube.com/@PolevoysProgramming) — [Полный плейлист по книге Скотта Мейерса "Современный и эффективный C++"](https://youtube.com/playlist?list=PL9aFcBWVu5htdYy3scDw9oNdw9Lrff59S&si=q1jZHl-osrEMu-tx)
Разбор книги Скотта Мейерса "Effective Modern C++" — уже не для новичков, а для тех, кто знает базовый синтаксис и хочет понять, *почему* современный C++ устроен именно так. Полевой не просто пересказывает книгу, а разжёвывает мотивацию за каждой фичей (зачем нужны r-value ссылки, почему move лучше copy, в каких случаях `auto` может сыграть злую шутку) и дополняет собственными примерами.

<details>
<summary>Затрагивающиеся темы</summary>

- **r-value ссылки**
- **Семантика перемещения**
- **Умные указатели**
- **Многопоточность**
- **auto**
- **Фигурная инициализация**
- **Шаблоны**
- **decltype**
- **using/typedef**

</details>
